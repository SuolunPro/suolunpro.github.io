# Data boundary

No real fixtures, official SP, betting-exchange funds or historical outcomes have been ingested yet.

Store only independently verified, time-stamped pre-match inputs. Use snapshots.freeze() to save immutable snapshots in an appropriate local folder; do not commit credentials or personal data.

The existing 2655 polluted historical records must never be imported or used for model evaluation.

A GitHub repository is code storage, not a running collector. Full daily coverage and official-SP verification remain unimplemented.
